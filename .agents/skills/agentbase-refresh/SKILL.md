# Update knowledge

Prepare no_change, one reviewable proposal or Incomplete for the approved repo.
Query handoffs grant preparation only; revalidate Hub/source/revision and obtain
agreement for broader scope. Cancellation retains private work.

1. `preflight_hub_ingest` must find one existing canonical Repository. A new one
   enters [Ingest](../agentbase-ingest/SKILL.md) for the same approved scope;
   ambiguity stops, without recursive handoff. Reuse the exact returned subject,
   never infer its home from checkout paths.
2. Select Delta for changed-source work. Explicit repair of sparse/missing
   knowledge or skill/model/profile coverage selects Coverage even on unchanged
   source. Age/count/debt alone does not authorize Coverage. For Coverage, inspect
   all five lanes broadly but boundedly in exact analysis_source_repository,
   then `prepare_hub_okf` with mode refresh, refresh_scope coverage and truthful
   coverage.partial/limitations. Delta uses omitted/default delta scope; no digest.
   Check resumed, createdAt and workspaceChanges: disclose earlier edits and old
   observation time. An owner-requested fresh start uses restart: true, retains
   the old bundle and selects the new session.
3. Read the complete source diff from the prior observed commit for every returned
   changed path. Delta investigates changes, known gaps then one small discovery
   pass. Coverage reconciles its prior broad pass; no second broad scan. Use
   optional `list_okf_schemas`/`get_okf_schema` for exact type guidance.
4. Follow agentbase-okf only in bundle. Preserve protected bytes, prepared paths,
   Repository home/navigation and foreign source contributions; Refresh cannot
   rehome. Missing evidence/omitted paths/time never authorize deletion. Recheck
   inherited template scalars; unsupported expressions and IAM-only interaction
   remain limitations. Keep independent runtimes separate and internals embedded.
   Repository links to children, without copying their sources/tables. Write
   about 60 body lines of wiring: role, entrypoint, trigger, linked IO/stores,
   flow-changing conditions, errors/retry/DLQ and operations; details stay in source.
   New known standalone concepts need an exact-schema structural path to Domain
   or Repository; Resource permits confirmed part-of or evidenced implemented-in,
   not declared-by or Resource-to-Resource depends-on. Shared concepts change
   only exact current-repo-owned structured entries; ambiguous prose stays intact.
5. Account for every sourceChanges.paths entry as updated/new/embedded/question/
   ignored with reason; materialized outcomes cite that exact current-repo path.
   Disclose omitted counts and partial coverage. Do not edit refresh_coverage;
   Finalize records/preserves debt and only non-partial explicit Coverage can
   clear it. No automatic repeated broad passes. Clean no-addition Coverage stops;
   review each proposed pass, cap three non-converged passes, keep debt visible
   and return ordinary work to Delta.
6. If concepts changed, `validate_okf_changes` with session_id, full changed
   Markdown and unchanged targets; each frontmatter relationship needs a resolving
   Markdown body link. One content repair maximum. With no changed concepts skip
   this non-empty-set tool; Finalize still validates normalized/runtime updates.
   Call `finalize_hub_okf_proposal` once with full accounting, Questions and
   explicit removals supported by exact existing current-repo evidence/reason.
   no_change needs no Inspect. Otherwise use proposal_id/proposal_digest and
   `inspect_hub_okf_proposal` once; review hunks/impact/counts/Questions/limits.
   Read private files or include_content when truncated. coverage.partial concerns
   investigation; changeAccounting.partial concerns delta. Read knownGaps.details.

For an approved multi-repo scope, opt into `scan_workspace_repositories` with
match_names: true. Verify both evidence chains of new nameSuggestions, keep
partial/duplicate names as Questions and read fullReport if truncated. Report
refreshSuggestions; reverse edges require separate Refresh of the evidence owner.
Provider gaps only offer [Enrichment](../agentbase-domain-enrichment/SKILL.md)
until scope/account/region/session approvals are obtained.

One stateless retryable INVALID_ARGUMENT correction is separate from one content
repair. Do not retry Prepare/Finalize, stale source/base, authority, integrity,
transport or uncertain state automatically. Report Incomplete with retained
workspace. No Publish, sync, clone, provider CLI or foreign-repo edits.
