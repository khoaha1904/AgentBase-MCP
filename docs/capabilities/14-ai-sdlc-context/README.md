AgentBase contributes relevant Published knowledge to a host workflow. The host
owns planning, implementation, investigation and source-tool selection. There is
no model runner, tracker fixture service, graph session, benchmark orchestration,
context store or second approval lifecycle in this capability. Historical
comparison results belong to AgentBase-Benchmark and Git history.
