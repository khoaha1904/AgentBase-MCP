# AI SDLC context requirements

> Status: Manual context composition remains active; model and graph
> qualification requirements and runners are retired.

- **AB-CONTEXT-011** - Explicit Query/Context invocation may supply bounded
  Published evidence inside another workflow; the host keeps its deliverable,
  lifecycle and approval authority.
- **AB-CONTEXT-012** - Start with one focused Published search and read exact
  concepts only when a concrete evidence gap remains. Do not prefetch an entire
  Hub, create a context packet or add durable context state.
- **AB-CONTEXT-013** - Keep Published concept/commit attribution separate from
  authorized source path/revision attribution. Preserve visible freshness and
  uncertainty; source access belongs to the host's existing tools.
- **AB-CONTEXT-014** - Missing Hub/source access returns the supported portion
  with a limitation. A repair handoff requires approval for its exact preparation
  scope and a later independent Publish confirmation.

`agentbase-context` delegates to `agentbase-query`. No graph or model process is
launched, no tracker mutation is owned, and no comparison campaign is a release
gate. Retired qualification IDs and results remain historical in Git and the
independent benchmark repository; they are not ongoing product obligations.
