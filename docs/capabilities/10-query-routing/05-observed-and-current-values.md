# 10.05 — Observed snapshots and current values

> Status: Host composition; snapshots are structured concept knowledge.

## Snapshot-default pipeline

Read relevant Published observations and exact provenance first. Stop when they
answer sufficiently. Only current/exact-code requests or tasks needing code add
an authorized source read. Age, available source or conflict is not a trigger.
If no snapshot exists, current evidence can answer, clearly labeled source-only.
Never ask users to choose internal modes or silently create a snapshot.

## Comparison outcomes

| Current source | Answer with snapshot |
| --- | --- |
| Not requested | Observed only, source_access not-checked. |
| Same typed scalar | Snapshot plus independently attributed current confirmation. |
| Different scalar | Both positions, provenance, Question/Guidance and conflict. |
| Ambiguous/missing/unauthorized | Snapshot plus exact degradation reason; no guess. |

Equality preserves types; 7, "7" and "7 days" differ. All relevant source roles
remain, rather than choosing newest/configuration evidence as truth.

## Current-source resolution

Match Repository identity and read only authorized paths. Observed spans are
historical hints, not durable current locators. Missing paths do not authorize
broad moved-symbol search. Report resolved or ambiguous from actual evidence;
include commit/dirty state only if known, never invent it. Do not read secret
paths or dump source/config/provider payloads into the answer.

## Age and freshness presentation

Observed time/age is context, not a trust score. Follow the
[freshness envelope](../08-live-references/08-freshness-envelope-requirements.md)
for identity-matched revision comparison; no fixed age threshold, probe or
scheduled Refresh. Current-path failure does not invalidate historical provenance.

## Published and Local Draft values

Draft is inspected separately. Current source is transient, not a publication
layer. Only a separately reviewed Refresh/Enrichment can write it back; ordinary
query creates no proposal, Question transition or publication. Exact observation
format/bounds belong to [08.01](../08-live-references/01-reference-format.md).
