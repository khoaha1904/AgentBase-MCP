# 10 — Published retrieval

> Status: Implemented; deferred boundaries are stated below.

Two public primitives provide bounded search and exact Markdown reads at remoteBase.
MiniSearch ranks metadata/body/heading sections; Domain scope includes canonical
members, Repository associations and one boundary hop. Freshness is advisory, never
source authority. Host skills compose answers and optional current-source
verification; no Draft overlay, model router, conflict scorer or hidden provider read
exists.
