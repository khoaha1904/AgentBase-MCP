# 03 — Source-backed candidate boundaries

> Status: Implemented; deferred boundaries are stated below.

The host agent investigates source and qualifies stable identity plus independent
query/contract/ownership/lifecycle value. MCP validates bounded observations and
source attribution, then locks Seed Inventory/Receipt. Embedded knowledge remains
parent-owned. There is no candidate database, scoring engine, semantic critic or
language-complete discovery promise.
