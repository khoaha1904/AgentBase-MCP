# 06 — Evidenced relationships

> Status: Implemented; deferred boundaries are stated below.

Canonical relationship identity is source/predicate/target with source-owned evidence
and a resolving body link. Bounded source-name matching produces hints/Questions,
never writes an edge. Published comparison suppresses only unambiguous exact
relationships. Provider verification is separately approved AWS/SQS enrichment;
merge/redirect and other provider profiles remain deferred.
