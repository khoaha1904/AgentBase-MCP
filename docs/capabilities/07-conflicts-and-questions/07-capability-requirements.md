# 07.07 — Capability requirement routes

This page is the normative requirement index for Conflicts, Questions and
Maintainer Guidance. Definitions stay with the authoring, publication and
enrichment runtimes that enforce their atomic transitions.

| Behavior | Normative requirements |
|---|---|
| Durable correction, defer and protected knowledge | [`AB-MVP-016..019`](../05-knowledge-entry/06-runtime-requirements.md#repository-proposal-lifecycle) |
| Shared Question identity, rendering and answer authority | [`AB-QUESTION-001..006`](../11-review-and-publish/01-runtime-requirements.md#reviewable-pr-publication) |
| Profile Repository Refresh and shared Question/Guidance paths | [`AB-PROFILE-LIFECYCLE-001..010`](../02-hub-domain-repository-model/09-profile-refresh-guidance-requirements.md) |
| Compact Question home and Guidance placement | [`AB-COMPACT-011..012`](../02-hub-domain-repository-model/10-compact-profile-layout-requirements.md#requirements) |
| Question references from observed values | [`AB-VALUE-009`](../05-knowledge-entry/06-runtime-requirements.md#observed-values) |
| Bounded three-tier provider resolution | [`AB-ENRICH-001..014`](../06-cross-repository-relations/07-runtime-requirements.md) |

Conflicting claims retain provenance. Guidance is scoped evidence, not an
automatic truth winner, and every correction or resolution remains reviewable.
