# 07 — Shared governance

> Status: Implemented; deferred boundaries are stated below.

Competing claims coexist with provenance. Finalize renders receipt-bound or observed-
value Questions as normal Hub Markdown; private caches have no authority. An exact-
revision human answer prepares attributed Maintainer Guidance and never publishes
implicitly. Query presents conflicts without choosing truth. Automatic needs-review
inference and concept merge remain deferred.
