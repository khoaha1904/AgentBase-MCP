# Quickstart: Scalable Hub Navigation Verification

1. Run focused schema tests and confirm canonical evidenced edges pass while a
   newly authored inverse/unsupported known-schema predicate fails.
2. Build a generated accepted Hub with ten domains, duplicate names and at
   least one thousand concepts.
3. Search a duplicate term without Domain and observe `scope_required`; repeat
   with one Domain and observe only scoped summaries.
4. Traverse one exact flow/resource outbound and inbound with depth two and
   confirm direction, evidence, commit and bounds.
5. Prepare a refresh for one source repository and inspect the bounded
   continuity manifest; multiply unrelated concepts and confirm its relevant
   membership is unchanged.
6. Validate a changed concept plus unchanged target summaries without sending
   the generated Hub.
7. Run the sequential cross-repository qualification and full `npm run verify`.
8. After offline acceptance, rerun Shopping Cart with the immutable prompt,
   inspect owner-review findings and publish one replacement Hub PR.
