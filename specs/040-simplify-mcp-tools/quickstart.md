# Quickstart: Simplify MCP Tools

1. Run the existing MCP server test and verify the tool count is 42.
2. Inspect `index_repository` from the client listing and confirm its schema has
   no persistence, target-project or cross-repository option.
3. Exercise controlled indexing, architecture read and sequential repository
   switching through the existing test.
4. Run `npm run verify`; do not run a model benchmark.
