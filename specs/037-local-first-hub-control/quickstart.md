# Quickstart: Release Qualification

Run sequentially; stop on the first blocker.

1. Isolated fresh home: prove Code Graph/status create no Hub.
2. Initial Ingest without remote: lazy local Hub, inspect, Accept, restart/query.
3. Store a profile credential through the masked terminal flow; connect exact
   GitHub.com or Enterprise-shaped URL/branch.
4. Status current, remote-ahead, unavailable and malformed-pending cases.
5. Explicit sync success/conflict/recovery; prove Published ref and drafts.
6. Real Init proposal: PR, maintainer merge, sync and query.
7. Real Refresh: PR, merge, sync and query; omission deletes nothing.
8. Question exact-revision answer through review/PR/merge/sync.
9. Batch Initial Ingest, captured AWS Enrichment and Hub CI/Initialization
   regression on the configured branch.
10. Run `npm run verify`; record real versus captured external evidence.
