# Quickstart: qualify the 2D Domain site

1. Run the focused visualization test.
2. Generate one Retail and one Crawler snapshot from the exact synchronized
   Published commit into new directories.
3. Serve each directory with a static local server.
4. Confirm the map and local assets return HTTP 200; select a node, focus one
   hop, toggle Flow edges and reset.
5. Confirm the output contains no `three` asset or 3D/WebGL wording.
6. Run `npm run verify` before rebuilding the Pages repository.
