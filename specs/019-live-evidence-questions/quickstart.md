# Quickstart: Live Evidence and Governed Questions Verification

1. Prepare a disposable Hub proposal from a repository containing incompatible
   documentation and implementation TTL evidence.
2. Author two validated live claim references without a durable TTL scalar and
   finalize one linked question declaration.
3. Confirm the question is absent before acceptance, inspect/accept the proposal,
   then confirm exactly one pending question survives a fresh runtime instance.
4. Read the accepted live evidence, bind the source repository, resolve both
   references through graph/snippet tools and present both roles without a winner.
5. Change the implementation TTL without re-ingesting OKF; repeat the workflow and
   confirm the new observation and current source identity are reported.
6. Remove or make the target ambiguous and confirm no old scalar is returned.
7. Answer the question as an identified maintainer; confirm it becomes resolved,
   retains every claim/history event and returns one reviewable guidance proposal.
8. Confirm accepted Hub bytes are unchanged until inspect/accept, then accept and
   query documentation, implementation and guidance as separate evidence roles.
9. Repeat an incomplete ingest and a process restart; confirm no claim, question or
   guidance is implicitly deleted.
10. Run `npm run verify`. Do not run a real model benchmark, rebuild PR #7 or publish
    until the owner separately approves qualification/publication.
