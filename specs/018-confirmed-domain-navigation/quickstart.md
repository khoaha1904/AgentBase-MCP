# Quickstart: Confirmed Domain Navigation Verification

1. Prepare a disposable repository proposal with confirmed Domain
   `domains/commerce` / `Commerce`.
2. Confirm the response selects Domain and returns the exact deterministic
   owner-guidance resource.
3. Author a Domain, System membership, `domains/index.md` and an additive root
   link while preserving `# AgentBase-Hub`.
4. Finalize and confirm the proposal is valid.
5. Repeat with a changed root heading and confirm finalization rejects it.
6. Prepare without confirmed Domain and confirm existing evidence-led selection
   does not invent Domain.
7. Run `npm run verify`.
8. Run the immutable V10 Shopping Cart qualification, inspect Domain → System
   navigation, then publish one replacement PR without merge.
