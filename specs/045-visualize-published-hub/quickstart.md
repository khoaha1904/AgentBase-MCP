# Quickstart: qualification route

## Deterministic gate

1. Build the projection twice from the same fixture commit and compare bytes.
2. Prove governance documents/candidates are excluded and active Questions are
   badges.
3. Prove every display direction comes from the predicate registry or Flow step.
4. Exercise diagram ready/insufficient outcomes.
5. Generate a site into a new directory, scan it for secrets/absolute paths and
   verify all receipt digests.
6. Run the site from a static local server with Hub/MCP access unavailable.
7. Run `npm run verify` and confirm the official tool list increased by at most
   the one approved visualization tool.

## Model-backed diagram qualification

After deterministic packet qualification passes **and the rich Domain below is
published**, invoke the released `agentbase-diagram` skill once per supported
type. Review that the rendered artifact preserves packet topology/direction and
visibly handles omissions. Do not claim model qualification from a synthetic
topology or force missing Dependency/Sequence data into the old sparse Hub.

## Rich Domain qualification

Only after implementation is green:

1. make one recoverable commit that resets current Hub knowledge while
   preserving README, CI and Git history;
2. ingest the eight selected Sock Shop service repositories;
3. publish/review the resulting knowledge;
4. qualify cross-repository diagrams and one static Domain site, including the
   model-backed skill runs above;
5. add the deployment repository only if the service batch cannot cover an
   important accepted diagram.

No AWS CLI is required for this qualification. Provider-enriched edges remain a
later improvement.
