# AHA Health Event State Store

The deployment creates `DynamoDBTable` for a single-region deployment or `GlobalDDBTable` for a multi-region deployment. Both use event ARN as the partition key and retain event status and update information with TTL.

Limitation: the concrete physical table name is generated by CloudFormation and is not fixed in source.
