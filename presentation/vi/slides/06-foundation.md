# Slide 06 — Ba foundation

## Vai trò của slide

Giới thiệu đủ technology để main audience hiểu credibility, không đi vào wire
protocol hay implementation detail.

## Thông điệp duy nhất

OKF giữ knowledge portable, MCP đưa nó vào workflow và exact source giữ kết luận
có thể kiểm tra.

## Nội dung hiển thị

```text
OKF                 MCP                 SOURCE EVIDENCE
Markdown + metadata contract access     repo · revision · path · lines
portable knowledge  agent integration   verification authority

Agent reasons and authors · MCP validates boundaries · Humans publish
```

## Lời thoại dự kiến

“OKF cho mình một convention mở dựa trên Markdown và metadata thay vì format chỉ
AgentBase hiểu. MCP cung cấp đường truy cập có contract cho agent. Code Graph có
thể giúp điều hướng, nhưng exact source ở revision đã khóa mới là evidence. Sự
phân vai quan trọng hơn tên công nghệ: agent reasoning, MCP giữ boundary và con
người giữ publication authority.”

## Câu chuyển

“Ba foundation đó đi vào một lifecycle duy nhất từ evidence đến shared
knowledge.”
