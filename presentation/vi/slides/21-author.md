# Slide 21 — Author

## Vai trò của slide

Giải thích cách giảm format drift trong AI-authored knowledge.

## Thông điệp duy nhất

MCP scaffold structure; agent enrich meaning từ evidence trong workspace sửa
được.

## Nội dung hiển thị

```text
MCP SCAFFOLD                  AGENT ENRICHMENT
path · ID · frontmatter       purpose · behavior
allowed relations             architecture · limitations
                 \           /
               EDITABLE WORKSPACE
```

## Lời thoại dự kiến

“Nếu agent tự tạo path, YAML, ID và relation từ đầu, format dễ drift. MCP tạo
workspace và skeleton theo contract; agent tập trung vào nội dung dựa trên
evidence. Ở bước này workspace vẫn sửa được và chưa có publication authority.”

## Câu chuyển

“Agent không thể tự chứng nhận output do chính nó vừa viết.”
