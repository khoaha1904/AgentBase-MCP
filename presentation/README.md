# AgentBase presentation source

This directory keeps presentation content with the product repository so one
approved repository transfer carries both the runtime and its explanatory
material.

The canonical working deck is the Vietnamese source under [`vi/`](vi/). It is
intentionally renderer-neutral: each slide records its purpose, visible content,
speaker notes, transition and sources in Markdown. No PowerPoint generator,
browser automation package or presentation-library dependency is required by
this repository.

An approved company tool may render these specifications into HTML, PowerPoint
or another delivery format. Rendering must preserve the accepted sequence and
narrative unless the owner reviews a content change.

Generated HTML, PPTX files, screenshots and local renderer toolchains are not
canonical presentation source and are excluded from this directory.
