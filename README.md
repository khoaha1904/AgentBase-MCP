# AgentBase Next

AgentBase Next is a clean rebuild of AgentBase around two explicit products:

1. local Code Intelligence that helps coding agents navigate a repository
   quickly and cheaply; and
2. governed OKF knowledge that accumulates reviewed, provenance-bearing
   understanding across repeated investigations.

The temporary repository name avoids colliding with the existing AgentBase
repositories. The intended product name remains **AgentBase**.

This repository currently contains the product reset, architecture constraints,
decision records and the first foundation specification. It deliberately does
not contain migrated runtime code yet.

## Start a session

From the `AgentBase` workspace, enter this repository and let the agent follow
`AGENTS.md`:

```bash
cd /home/khoa/workspace/AgentBase/agentbase-next
```

The recovery entrypoint is `docs/handoff.md`.
